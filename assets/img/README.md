# Imagery

This folder is intentionally empty in v1.

Everywhere a photograph belongs, the app renders a solid `--hc-cream` block
through the `media()` component in `js/components.js`. That is deliberate.
Home Church uses real, warm, candid photographs of actual people in the actual
room, and a placeholder block is honest where stock photography would be a lie.

When real imagery arrives, drop it here and give `media()` an `src`. Keep the
paths relative, keep the grading warm, and never reach for a stock library.
