# Demo photos, temporary

Five Instagram photos for the Connect rail, so the team can see it working
before the real sync exists.

**Upload the image files here.** Filenames do not matter, they get matched to
their permalinks by what is in the picture.

This folder is temporary and gets deleted once the images are in Supabase
Storage. Nothing in the app reads from it, and it is deliberately not merged
to main, so these photos stay out of the main branch's history.
